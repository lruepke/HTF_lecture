Lecture overview
================

We start with a short primer on meshes and time steps, the two basic ingredients of every numerical model. Then we will make our first 2-D and 3-D Navier-Stokes flow simulations and learn how to use parallel-processing to speed up the simulation time.

We will also learn how to make simple meshes with OpenFOAM's blockMesh utility.
