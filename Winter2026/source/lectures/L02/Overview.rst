Lecture overview
================

We start with a short primer on meshes and time steps, the two basic ingredients of every numerical model. Then we will run our first 2-D and 3-D Navier-Stokes flow simulations and learn how parallel processing can reduce computing time.

We will also learn how to make simple meshes with OpenFOAM's :code:`blockMesh` utility, compare runs, and diagnose errors in case files.
